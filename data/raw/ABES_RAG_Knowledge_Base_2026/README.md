# ABES Engineering College — RAG Knowledge Base
Phase 1 demo dataset — 30 September 2026

DATA CLASSES
- OFFICIAL_PUBLIC: taken from publicly available ABES Engineering College pages/documents.
- DEMO_SYNTHETIC: generated only where the public source does not provide operational data. It must never be presented as official.

IMPORTANT
The public ABES sources found provide faculty names/designations but do not publish an authoritative faculty-to-cabin map. Therefore all cabin assignments in teacher_seating_plan.csv are DEMO_SYNTHETIC.
