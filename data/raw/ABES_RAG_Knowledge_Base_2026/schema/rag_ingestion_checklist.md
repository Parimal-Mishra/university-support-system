# RAG Ingestion Checklist
[1] Verify official source
[2] Store source URL
[3] Record version/effective/review dates
[4] Separate official and synthetic data
[5] Clean and extract text
[6] Chunk by semantic section
[7] Attach metadata
[8] Generate embeddings
[9] Store vector references
[10] Test retrieval
[11] Test grounded answers
[12] Test fallback/unanswerable queries

Source priority:
current approved ABES document > current ABES official webpage > older official source > synthetic demo data.
